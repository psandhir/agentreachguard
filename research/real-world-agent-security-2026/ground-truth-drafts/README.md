# Ground-truth first-pass drafts

These 180 files are **not locked ground truth**. They are a source-only first adjudication scaffold created after cohort freeze and before any HorusTrace execution.

Each draft records the frozen repository/SHA/application path, framework stratum, original discovery evidence, Tier B/Tier C membership, and the unresolved structural fields that require detailed reviewer verification.

Rules:

- Do not copy a draft into `ground-truth/` without reviewing the pinned source.
- Do not inspect HorusTrace output during review.
- Tier A cases require at least one final reviewer.
- Tier B and Tier C cases require at least two distinct final reviewers.
- Tool, MCP, delegation, authority, attack-path and deployment/IAM truth must be source-evidenced; unresolved is preferred over guessing.
- `ground_truth_locked` must remain false until all 180 final files satisfy the study validator.

The purpose of this directory is to make review progress auditable without falsely claiming that dual review has occurred.
