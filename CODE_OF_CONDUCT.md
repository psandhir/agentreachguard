# Code of Conduct

AgentReachGuard is an open-source security project. Contributors are expected to keep technical discussion professional, evidence-based, and constructive.

## Expected behaviour

- Treat contributors with respect, including when reviewing incorrect or incomplete security claims.
- Critique code, threat models, rules, and evidence rather than people.
- Clearly distinguish demonstrated vulnerabilities from hypotheses.
- Avoid publishing sensitive information, real credentials, customer data, or exploit details that put users at immediate risk.
- Give contributors a reasonable opportunity to correct mistakes.

## Unacceptable behaviour

Harassment, discrimination, threats, deliberate disruption, doxxing, credential exposure, or knowingly misleading vulnerability claims are not acceptable.

## Reporting conduct issues

For ordinary project disagreements, use the relevant issue or pull request. For sensitive conduct or security matters, contact the maintainer privately rather than posting details publicly.

Maintainers may edit, hide, lock, or remove content and may restrict participation when necessary to protect the project and its contributors.
