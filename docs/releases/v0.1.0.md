# AgentReachGuard v0.1.0

The first public alpha focuses on deterministic, five-layer security analysis and first-class Google ADK Python support.

## Highlights

- Five connected analysis layers: configuration, capabilities, identity, reachability, and attack paths.
- First-class Google ADK Python 2.x and Agent Config YAML static analysis.
- OpenAI Agents SDK and common MCP configuration support.
- Delegated authority across ADK sub-agents and `AgentTool`.
- ADK MCP, A2A, shell/code execution, computer use, BigQuery and Google API toolset checks.
- GCP/Azure/AWS Terraform IAM evidence feeding identity analysis.
- Framework-neutral manifest for business intent, data classification, resource scope, egress, and capability budgets.
- Console, JSON and SARIF output suitable for CI.
- Secure and intentionally vulnerable reference fixtures.

## Current boundary

This is an alpha static analyser. It does not execute scanned repositories, launch MCP servers, prove prompt-injection exploitability, or resolve live cloud IAM during a normal scan. Live GCP authority resolution is planned next.
