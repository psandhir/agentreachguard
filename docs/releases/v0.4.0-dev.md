# HorusTrace v0.4 development milestone

v0.4 moves HorusTrace from repository-level capability reachability toward
path-aware agent security analysis.

## Current development implementation

- Versioned Agent Dependency Graph (ADG) with typed nodes and edges.
- Explicit data-flow, control-flow, delegation, identity, memory, and network
  relationships.
- Bounded cross-file static source-to-sink analysis for supported Python constructs.
- Path-backed `PATH001` findings with `supported` confidence when static data flow
  is established.
- `PATH007` for supported untrusted-input to agent-memory/checkpoint write paths.
- Supported secret-to-external-send paths can strengthen `PATH003` evidence.
- SARIF `codeFlows` for supported static paths.
- Agent Bill of Materials (AIBOM) generation.
- `horustrace graph` and `horustrace aibom` CLI commands.
- Initial LangGraph `StateGraph` / `MessageGraph` adapter with control-edge and
  checkpoint-memory normalization.
- OpenAI Agents handoff/delegation normalization.
- Prompt inventory by digest only; prompt contents are not emitted in ADG/AIBOM.

## Deliberate boundaries

The v0.4 flow engine is not arbitrary-Python formal taint analysis. Runtime
exploitability, live cloud authorization, SAT/SMT policy solving, runtime action
blocking, and autonomous prompt modification remain outside this milestone.
