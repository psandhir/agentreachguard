# AgentReachGuard v0.2.0

v0.2 is a pilot-ready static-analysis release. It adds the rule catalogue, OWASP coverage references, potential path confidence, stable diagnostics, hostile-repository limits, path containment, repository rule configuration, and a 25-case reviewed benchmark with measured precision and recall of 1.000.

There are no intended breaking changes to documented v0.1 commands or manifest formats. The scanner does not prove runtime exploitability, runtime control effectiveness, or complete live cloud authority.
