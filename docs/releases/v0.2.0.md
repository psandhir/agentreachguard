# AgentReachGuard v0.2.0

v0.2 is a pilot-ready static-analysis release focused on reliability and evidence quality. It adds the rule catalogue, OWASP coverage references, explicit potential-path confidence, stable coverage diagnostics, hostile-repository limits, canonical path containment, repository rule configuration, and a reviewed 26-case benchmark.

The benchmark includes secure and vulnerable execution, delegation, MCP, identity, data/network and attack-path cases, plus a deliberately dynamic configuration case where incomplete static analysis and its exact coverage diagnostic are expected. The release snapshot records precision and recall of 1.000 against this reviewed fixture corpus; this is a regression metric for the corpus, not a claim of real-world universal scanner accuracy.

There are no intended breaking changes to documented v0.1 commands or manifest formats. The scanner does not prove runtime exploitability, runtime control effectiveness, or complete live cloud authority.
