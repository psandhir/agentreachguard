# HorusTrace v0.5.0

HorusTrace v0.5.0 turns the project from a collection of framework-aware security
detectors into a more explicit **effective-authority and attack-path analysis
platform for agentic systems**.

The release is built around four foundations: a versioned Agent Security Graph,
semantic Authority Delta, bounded inbound runtime provenance, and a public framework
adapter contract.

## Highlights

### Agent Security Graph v1

A new `horustrace security-graph` command exports a deterministic, versioned
security graph that co-locates:

- framework-neutral dependency topology;
- effective-authority relationships;
- static data-flow evidence;
- attack paths;
- analysis coverage and unresolved evidence.

Repository paths are normalized and the canonical graph digest is stable across
checkout locations. Existing `horustrace graph` output remains backward compatible.

### Authority Delta v1

`horustrace diff` now compares effective-authority relationships semantically,
rather than only reporting low-level graph changes.

Authority expansion can be attributed to concrete changes such as:

- new capabilities;
- attached or changed identities;
- additional IAM roles or permissions;
- additional OAuth scopes;
- weakened approval/control requirements;
- widened MCP tool scope;
- newly reachable resources;
- newly reachable destinations;
- entirely new authority relationships.

The same Markdown output is consumed by the existing GitHub Action, so pull-request
reviews can surface effective-authority expansion directly.

### Inbound runtime provenance

Static flows can now carry bounded reverse-call evidence showing which entrypoints can
reach a security-relevant helper.

The implementation understands class methods, CLI roots, application/runtime roots,
and MCP-server lifecycle paths. High-cardinality test or CLI roots cannot consume the
entire evidence budget before a different runtime entrypoint kind is represented.

This provenance improves explanation without changing reachability merely to reduce
unknown counts.

### Framework adapter contract v1

HorusTrace now defines a public static adapter contract for framework-specific source
normalization.

`horustrace adapters` exposes the built-in adapter catalogue and contract version.
Adapters emit the normalized HorusTrace graph model and must not import or execute the
target application.

Automatic loading of arbitrary installed third-party plugins is intentionally outside
contract v1 so installing a Python package does not silently expand HorusTrace's trust
boundary.

## Effective-authority hardening

v0.5.0 also includes the effective-authority and research-driven hardening completed
after v0.4.1:

- generic agent-to-tool and agent-to-MCP effective-authority reconstruction;
- stable authority relationship identifiers and explicit resolution dimensions;
- inherited approval/control evidence;
- richer identity, resource, destination, mutation and network semantics;
- FastAgent YAML MCP discovery and contextual binding;
- OWASP Top 10 for Agentic Applications 2026 mapping and runtime/source-context views;
- authority-aware rule consumers;
- residual unknown-flow telemetry;
- subprocess executable-control precision fixes;
- explicit non-agent execution-context proof.

## Frozen-90 validation

The release candidate was exercised against the frozen 90-repository public corpus.

All 90 repositories cloned and scanned with:

- **0 scanner errors**
- **0 scanner timeouts**
- **2,076 agents**
- **3,413 tools**
- **633 MCP servers**
- **78 identities**
- **140 static flows**
- **6 proven agent-reachable flows**
- **133 proven non-agent flows**
- **1 intentionally unknown flow**
- **25 attack paths**
- **2 static-dataflow-backed attack paths**

The sole residual unknown remains in pinned `ArcadeAI/arcade-mcp`. The relevant
OAuth-refresh helper is genuinely shared by CLI and MCP-server runtime paths, so
HorusTrace preserves the ambiguity rather than inventing a reachability conclusion.

Pinned validation on that repository recovers the MCP lifecycle path:

```text
MCPServer.__init__
→ _init_arcade_client
→ _load_config_values
→ get_valid_access_token
→ refresh_access_token
```

while retaining `agent_reachability: unknown`.

## Safety model

HorusTrace remains static-first and local-first.

It does not need to:

- import target Python modules;
- execute an agent;
- start an MCP server;
- authenticate to production cloud/SaaS systems;
- fetch live IAM bindings;
- infer runtime effectiveness from configuration presence.

When static evidence is incomplete, the release continues to report unresolved or
unknown state rather than guessing.

## Compatibility

Existing ADG export, scan output, rule identifiers, configuration filenames and
finding fingerprints remain supported. The ASG and adapter catalogue are additive
interfaces.

Install after release with:

```bash
pip install --upgrade horustrace==0.5.0
```
