# Support

HorusTrace is an early-stage open-source project.

- **Bug or false positive:** open a GitHub issue using the bug template.
- **New rule or framework support:** use the rule/feature proposal templates.
- **Security vulnerability in HorusTrace:** follow [SECURITY.md](SECURITY.md) and do not disclose exploit details in a public issue.
- **General usage question:** open a GitHub Discussion when Discussions are enabled; otherwise use an issue with a concise reproduction.

When reporting scanner behaviour, include the HorusTrace version, command used, a minimal synthetic fixture where possible, and the expected vs actual finding.
